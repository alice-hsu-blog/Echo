# Echo

Echo is a desktop app for building a personal "writing-material database": collect quotes you expect to reference in your future writing, tag each one with the "scenarios" it might be used in, and log an "imitation practice" under each scenario, practicing turning what you've read into your own words.

## Features

- **Quotes** — the core unit: record quotes, with the ability to note their source.
- **Scenario tags** — tag a quote with one or more usage-scenario tags, making it easier to connect the quotes you've collected with the scenarios you'll write about in the future. The next time you need inspiration, just click a scenario tag and browse the quotes you've collected under it to find it.
- **Imitation practice** — under each scenario, practice writing your own imitation of the quote. This helps turn input into output, instead of just hoarding quotes — and the practice also helps your future self when you need writing inspiration.
- **Import / Export** — through the "File" menu, back up your whole database as a JSON file, and import someone else's JSON file too, to exchange writing practices with each other.

## Installation

Go to the [Releases](https://github.com/alice-hsu-blog/Echo/releases) page, download the installer matching your computer's operating system (macOS, Windows, or Linux), and follow that OS's usual installation steps after opening it.

> The installers are currently unsigned, so your operating system may show a one-time security warning when opening the app (macOS's Gatekeeper or Windows' SmartScreen) — click "Open Anyway" / "Run anyway" to launch the app normally.

# Echo

Echo 是一個桌面應用程式，用來建立個人的「寫作素材資料庫」：收集你未來會在寫作中引用的佳句，為佳句標上將來可能使用的「情境」標籤，並在每個情境底下記下「仿寫練習」，練習將讀到的東西內化成自己的文字。

## 功能特色

- **名言佳句**——最核心的單位：可記錄名言佳句，含記錄出處的功能。
- **情境標籤**——為佳句標上一個或多個使用情境標籤，讓你更容易把收集到的名言佳句，跟未來寫作的使用情境連結起來。等到下回需要靈感時，即可點選情境標籤，透過瀏覽過往搜集的句子來找尋靈感。
- **仿寫練習**——在每個情境底下，練習仿寫句子。這能幫助你將輸入化為輸出，而不只是單純囤積句子。仿寫練習也能幫助未來需要寫作靈感的自己。
- **匯入／匯出**——透過「檔案」選單，將整個資料庫備份為 JSON 檔案，也能匯入別人的 JSON 檔案，彼此交流寫作練習。

## 安裝方式

請前往 [Releases](https://github.com/alice-hsu-blog/Echo/releases) 頁面，下載符合你電腦作業系統（macOS、Windows 或 Linux）的安裝檔，開啟後依照該作業系統一般的安裝流程操作即可。

> 目前的安裝檔尚未經過簽章，因此開啟時你的作業系統可能會跳出一次性的安全性警告（macOS 的 Gatekeeper 或 Windows 的 SmartScreen），此時點選「仍要開啟」／「仍要執行」即可正常啟動應用程式。
